## OpenClaw Gateway 实现

实现了完整的 OpenClaw Gateway 网关服务，参考用户提供的 OpenClaw 协议规范。

### 核心文件
- `gateway/protocol.go` - 协议帧定义（req/res/event）、错误码、presence、snapshot
- `gateway/config.go` - 配置结构，支持 auth/ reload/ canvasHost、dev 模式派生端口
- `gateway/service.go` - 核心服务，整合 Host，支持 health/status/system-presence/send/agent/node.* 方法
- `gateway/websocket.go` - WebSocket 控制平面，握手协议、帧处理、presence、tick 保活
- `gateway/http.go` - HTTP 多路复用，OpenAI Chat Completions/Responses/Tools Invoke 端点
- `gateway/server.go` - 主服务器，单端口 WS+HTTP 混合、热重载（SIGUSR1）
- `cmd/gateway/main.go` - CLI 入口

### CLI 用法
- `af gateway`（默认端口 18640）
- `af gateway --verbose`
- `af gateway --force`（终止占用端口进程后启动）
- `af --dev gateway`（dev 模式，隔离配置/状态）
- `af --profile <name> gateway`（多配置文件）

**配置文件示例** (`~/.openclaw/openclaw.json`)：
```json
{
  "gateway": {
    "port": 18640,
    "host": "127.0.0.1"
  }
}
```
