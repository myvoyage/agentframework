### 开发流程

1. **分支策略**
   ```
   main (生产)
     ↑
   develop (开发)
     ↑
   feature/* (功能)
   hotfix/* (修复)
   ```

2. **提交规范**
   ```
   feat: add new feature
   fix: fix bug
   docs: update documentation
   test: add tests
   refactor: refactor code
   ```

3. **代码审查**
   - 每个PR必须审查
