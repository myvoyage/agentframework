## 💡 使用建议

### 1. 立即应用新功能

#### 安全功能
```go
// JWT 验证（强制签名）
sub, err := auth.ValidateJWTWithSecret(token, aud, secret, "HS256")

// 输入验证
validator := validation.EmailValidator()
sanitized, err := validator.ValidateAndSanitize(input)

// RBAC 权限
rbac := rbac.NewRBACManager()
if !rbac.CheckPermission(userID, "agent", "read") {
    return ErrAccessDenied
}
```

#### 性能功能
```go
// 使用对象池
msg := pool.DefaultMessagePool.Get()
defer pool.DefaultMessagePool.Put(msg)

// 使用无锁结构
registry := lockfree.NewAgentRegistry()
registry.Register(id, agent)

// 批量处理
processor := batch.NewBatchProcessor(handler, 100, 5*time.Second)

// 多层缓存
value, err := multiCache.Get(ctx, key)
```

#### 代码质量功能
```go
// 统一错误处理
errHandler := errors.NewHandler("module", logger)
return errHandler.Handle("operation", err)

// 配置验证
type Config struct {
    Name string `validate:"required"`
}
if err := config.ValidateStruct(&cfg); err != nil {
    return err
}
```
